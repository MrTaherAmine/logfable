# ATT&CK Mapping Methodology

Baseline: MITRE ATT&CK 19.2, released 5 August 2026.

Mappings record technique ID, tactic, scenario step, rationale, evidence sources, confidence, provenance, and review status. Detection Strategies, Analytics, and Data Components are included only when the project has a verified current reference; blank arrays mean “not curated for this mapping,” not “none exist.”

A generated event mentioning or representing a technique does **not** prove that a detector covers the technique. LogFable therefore labels mapping output as expected observable coverage, with benchmark results handled separately.
