# Ethical Use and Safety

LogFable is a defensive synthetic-telemetry generator. It does not attack systems, deploy payloads, harvest credentials, transmit generated events, or contact real targets. Bundled scenarios use fictitious identities, private/documentation IP ranges, `.example` names, and inert placeholders.

Vendor-inspired source names mean “synthetic compatibility-oriented representation,” not proprietary parity. ATT&CK and D3FEND mappings describe behavior/evidence and defensive opportunities, not guaranteed prevention or detection.
