# About LogFable

**LogFable** — *Generate complete cyber incidents without launching a single attack.*

LogFable is a local-first scenario-as-code engine for deterministic, causally coherent, multi-source synthetic cybersecurity telemetry. It is designed for SOC training, detection engineering, SIEM validation, cyber ranges, research, education, and defensive-product testing without launching attacks against real systems.

## Product identity

LogFable generates synthetic representations of security events. It does not launch attacks, execute malware, exploit targets, or transmit generated telemetry automatically. Vendor-inspired telemetry is compatibility-oriented synthetic data and is not presented as byte-for-byte proprietary vendor output.
